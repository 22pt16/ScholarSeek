# ScholarSeek

### Lightweight Hybrid Information Retrieval System for Research Papers

ScholarSeek is an Information Retrieval project designed to search and rank
research papers using classical lexical retrieval and, as the project
develops, semantic retrieval.

## Current Features

- Document preprocessing
- Inverted index
- TF-IDF retrieval
- BM25 retrieval
- Query processing
- Ranked search results
- Research-paper oriented corpus

## Planned Features

- Semantic retrieval using sentence embeddings
- Hybrid BM25 + semantic ranking
- Query expansion
- Research-paper metadata-aware ranking
- Precision@K evaluation
- Retrieval method comparison

## Technology

- Python
- Flask
- Classical Information Retrieval
- TF-IDF
- BM25
- Sentence Transformers
